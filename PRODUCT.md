## Platform

web

## Users

Unity developers and studio teams evaluating or operating a game backend.

## Product Purpose

Provide game backend services managed in a web admin and integrated into Unity through the SaiServer prefab.

## Operating Context

Developers configure a studio and game in the admin, connect the Unity prefab using the game ID, and test in Play Mode.

## Capabilities and Constraints

Existing capabilities include authentication and 2FA, cloud save, inventory, shops, gacha, crafting, quests, leaderboards, analytics, and server-side Lua scripting. Sai Play is the player-facing companion using the same account, with game discovery and played-game progress.
