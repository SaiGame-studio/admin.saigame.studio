Lua スクリプト入門

各ゲームには、プロジェクトで Lua Scripting を評価するための無料スクリプト枠が 1 つ用意されています。次の手順で最初のスクリプトを作成して実行します。

---

## 1. スクリプトの作成と編集
* **初期設定:** 有効な名前でスクリプトを作成します。この名前は、ゲームクライアントからスクリプトを呼び出すための一意の **キーワード** になります。
![alt](/tutorial-lua/hello-world/step-01.png)
  
* **エディターを開く:** スクリプト一覧の **Edit** アイコンをクリックして、内蔵の Web Lua エディターを開きます。
![alt](/tutorial-lua/hello-world/step-02.png)


## 2. エディター画面の使い方
エディターは主に 2 つの領域に分かれています。
* **スクリプト作業領域:** ロジックを記述するメイン領域です。
* **テンプレートライブラリ:** 右側にあります。**Core** タブを開き、`#1 tut_hello_output` を選択してサンプルコードを読み込みます。
![alt](/tutorial-lua/hello-world/step-03.png)

> **重要:** コードを変更した後は、必ず **Ctrl+S** を押すか、右上の **Save** アイコンをクリックしてください。

---

## 3. 実行とテスト
保存後、**Run Script** セクションまでスクロールしてロジックをテストします。

* **payload の入力:** payload 欄に自分の名前を入力します（画像の例を参照）。
* **実行:** **Run** をクリックします。
* **結果の確認:** **Run Result** に JSON レスポンスと実行時間（ミリ秒、ms）が表示されます。
![alt](/tutorial-lua/hello-world/step-04.png)

---

## 4. パフォーマンスの制限
サーバーの安定性とパフォーマンスを保つため、すべての Lua スクリプトに次の制限が適用されます。
- **最大実行時間**: 500ms

> **注意:** **500ms** を超えたスクリプトは強制終了されます。この時間内に収まるようにロジックを最適化してください。

---

## 5. Unity でのスクリプト実行
Web Editor でスクリプトを確認したら、ゲームクライアントに組み込めます。

* **実装:** Unity プロジェクト内の `BattleScript` クラスを開きます。
* **確認:** Unity 上でロジックを実行します。出力と動作が Web Editor の結果と一致することを確認できます。
![alt](/tutorial-lua/hello-world/step-05.png)
