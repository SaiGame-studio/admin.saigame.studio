Lua スクリプト入門

各ゲームにはデフォルトで **7 つのスクリプト枠** が用意されているため、すぐにプロジェクトで Lua Scripting を試せます。**Scripts** ページ上部のカウンターで使用中の枠数を確認でき、プラグインでこの上限を増やせます。次の手順で最初のスクリプトを作成して実行します。

![alt](/tutorial-lua/hello-world/step-00.png)

---

## 1. スクリプトの作成と編集
* **初期設定:** **新規スクリプト** をクリックして名前を入力します。名前は英小文字で始まり、英小文字・数字・アンダースコアのみ使用できます（例: `hello_world`）。この名前は、ゲームクライアントからスクリプトを呼び出すための一意の **トリガーキー** になります。
![alt](/tutorial-lua/hello-world/step-01.png)
  
* **エディターを開く:** スクリプト一覧の **スクリプトを編集**（鉛筆）アイコンをクリックして、内蔵の Web Lua エディターを開きます。
![alt](/tutorial-lua/hello-world/step-02.png)

> **注意:** **アクティブ** スイッチはオンのままにしてください。非アクティブなスクリプトは実行できません。

## 2. エディター画面の使い方
エディターは主に 2 つの領域に分かれています。
* **スクリプト本文:** ロジックを記述するメイン領域です。構文エラーは入力中にハイライトされ、サイズバーでスクリプト上限 **250 KB** の使用量を確認できます。
* **サンプルスクリプト:** 右側にあります。**Core** タブを開き、`#1 tut_hello_output` を選択してサンプルコードを読み込みます。**置換 / 追加** スイッチで、サンプルで現在のコードを置き換えるか末尾に追加するかを選べます。
![alt](/tutorial-lua/hello-world/step-03.png)

> **重要:** コードを変更した後は、必ず **Ctrl+S** を押すか、エディターツールバーの **保存** アイコンをクリックしてください。

---

## 3. 実行とテスト
保存後、**実行テスト** セクションまでスクロールしてロジックをテストします。

* **プレイヤープロフィール:** スクリプトは自分のアカウントとして実行されるため、このゲームのプレイヤープロフィールが必要です。**実行** ボタン横のステータスバッジを確認し、**プロフィールなし** と表示されている場合は **プロフィールを作成** をクリックします。バッジが **プロフィールあり** になると **実行** ボタンが有効になります。
![alt](/tutorial-lua/hello-world/step-04-profile.png)
* **payload の入力:** JSON 形式で payload を入力します。入力値は `payload` オブジェクトの中に記述します。
```json
{
  "payload": {
    "player_name": "Alice"
  }
}
```
* **実行:** **実行** をクリックします。
* **結果の確認:** **実行結果** に JSON レスポンスと実行時間（ミリ秒、ms）が表示されます。上の例では、output に `greeting = "Hello, Alice!"` と `processed = true` が含まれます。`player_name` を省略すると、挨拶は `"Hello, stranger!"` になります。
![alt](/tutorial-lua/hello-world/step-04.png)

> **ヒント:** payload エディター内で **Ctrl+S** を押す（または **保存** アイコンをクリックする）と、次回のために payload を保持できます。

---

## 4. 制限
サーバーの安定性とパフォーマンスを保つため、すべての Lua スクリプトに次の制限が適用されます。
- **最大実行時間**: 500ms
- **最大スクリプトサイズ**: 250 KB

> **注意:** **500ms** を超えたスクリプトは強制終了されます。この時間内に収まるようにロジックを最適化してください。

---

## 5. Unity でのスクリプト実行
Web Editor でスクリプトを確認したら、ゲームクライアントに組み込めます。

* **実装:** Unity プロジェクト内の `BattleScript` クラスを開きます。
* **確認:** Unity 上でロジックを実行します。出力と動作が Web Editor の結果と一致することを確認できます。
![alt](/tutorial-lua/hello-world/step-05.png)
