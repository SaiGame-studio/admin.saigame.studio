Welcome! Let’s walk through the basic steps to get you started.

### 1. Create a Studio

- First, you need to create a Studio. This is your main workspace where everything is organized.
- Just enter a new studio name and click the Create button.
![alt](/tutorial-guides/create-a-studio/step-01.png)

### 2. Set Up a Team

Inside your Studio, you’ll need a Team.
![alt](/tutorial-guides/create-a-studio/step-02.png)

- If you’re working alone, you don’t need to add anyone. The system will automatically create a default team with just you in it.
- If you want to collaborate with others, ask them to register an account and send you their User ID. You can then add them to your team.
![alt](/tutorial-guides/create-a-studio/step-03.png)

### 3. Create Your First Game
- Next, create your first Game and assign it to your team. This helps keep your work organized and accessible to everyone in the team.
- Before you can add your game to the team, make sure you create it [here](/games/new)

Create Game![alt](/tutorial-guides/create-a-studio/step-04.png)

Add to the team![alt](/tutorial-guides/create-a-studio/step-05.png)

### Additional Notes
1. You can create unlimited Studios, Teams, and Games as long as you have enough sCoin.
1. There are no monthly fees for the number of Studios, Teams, or Games you create.
1. The system uses a one-time payment model, so you only pay once instead of recurring subscriptions.
2. Inside a game, you may need a monthly subscription, but we’ll talk about that later.
