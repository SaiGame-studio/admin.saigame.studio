The LeaderBoard class displays all game rankings (including disabled ones) directly in the Unity Inspector.

## Leaderboard provides the following functionality:
* In Unity, locate the **LeaderBoard** class within the **SaiServer** object.
* This component allows you to view all available leaderboards, including those that are currently disabled.
![alt](/tutorial-guides/leaderboard-for-player/step-01.png)
* **Get Top N:** Retrieve the top rankings for up to 50 players.
![alt](/tutorial-guides/leaderboard-for-player/step-02.png)

* **My Rank:** View the current rank and score of the logged-in player.
![alt](/tutorial-guides/leaderboard-for-player/step-03.png)
